# r9：内核默认支持、同目录视觉匹配与量化标签

- 移除内核管理中的能力探测入口。llama 启动不执行 --help、不按参数能力清单拦截，按标准参数直接启动；模型量化元数据不再用于判定内核是否支持。缺失文件、分片及运行库仍正常报错。
- 同目录 mmproj 默认关联到该目录下的模型。同目录多个 mmproj 时，优先名称/系列匹配，其次按文件路径排序选择；可以手动更改、禁用或恢复自动匹配。用户明确保存的选择优先。
- 量化标签从模型文件名提取，不再被 GGUF 的 general.file_type 覆盖或因冲突阻断。没有可识别标签时显示“未标注（可自定义）”；模型管理中可保存自定义量化标签。
- 保留 r8 本地 WebP 请求兼容处理与 r7 Harness 更新下载修复。

按用户要求，本次仅编译并制作完整便携压缩包，不执行自动化测试、界面验收、模型加载验证或压缩包回读校验。文件清单和 SHA-256 仅在生成交付文件时记录，不代表验证结果。
